# Cau truc chinh

Muc tieu la bieu dien dung so do trong tai lieu va de cac nhom de dang tim file.

## App

- Dinh tuyen, layout, va cac page trong App Router.
- UI tham khao duoc render tu folder design/ thong qua route /mockup/.

## libs

- core: tien ich dung chung (helper, xu ly HTML, component base).
- shared: model/type/enum dung chung.
- tts: ma nguon rieng cua du an ATVSLD.

## public

- Luu asset public (logo, icon, anh dung chung).

## src (tuy chon)

- Co the gom toan bo code vao src/ neu can doi cau truc ve sau.
